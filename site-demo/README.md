# EnerGo: демо нового сайта (исходники)

Утверждённое демо нового сайта energocharge.uz. Это статическая страница без сборки, открывается через любой статический сервер:

```bash
cd site-demo && npx serve .     # или python3 -m http.server
```

Живая версия: https://tsoyanatoliy7.github.io/energocharge/ (ветка `gh-pages`, собрана из этих файлов в один HTML).

> Из `file://` страница не откроется целиком: ES-модули и import map требуют http(s).

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | Вся разметка и стили, плюс основной скрипт: кинопроезд первого экрана, инструкции на станции, видеоинструкции, навигация по разделам |
| `js/station3d.js` | 3D-двойник станции на three.js: поворот к аварийной кнопке в разделе инструкций |
| `js/locations.js` | Карта всех локаций: SVG-карта, кластеры, фильтры, карточки станций. **Точка интеграции с API** |
| `js/uz-geo.js` | Границы областей Узбекистана (geoBoundaries ADM1, CC BY 4.0) и соседей (Natural Earth) |
| `js/partner.js` | Раздел «Как стать партнёром»: форматы, шаги, форма заявки. **Точка интеграции с CRM** |
| `js/i18n.js` | Переводы RU / UZ (латиница) / EN |
| `js/three.*.js`, `RoomEnvironment.js`, `lenis.min.js` | Библиотеки: three.js r187 и Lenis (плавный скролл) |
| `media/`, `brand/` | Фото станции, вырезки коннекторов, обложки видео, оригинальный логотип из брендбука |

Бренд: строго по брендбуку. Цвета `#FAFCF0` / `#02D866` / `#131214` / `#98DAF7`, шрифт Inter Tight, только оригинальный логотип.

## Что подключить перед продом

### 1. Карта станций → API приложения
Файл `js/locations.js`, объект `window.EnerGoLocations`:

- заменить `fetchStations()` на запрос к API действующей карты, функция должна вернуть `Promise<Station[]>`;
- либо передавать данные снаружи через `EnerGoLocations.setStations(list)`. Его можно вызывать повторно для живых статусов: выбранная станция и вид карты сохраняются;
- формат `Station` описан в шапке файла: `id`, `name`, `city`, `address`, `lat`, `lng`, `connectors[{type, kw, status}]`, `price`, `appUrl?`;
- после подключения удалить у `<section id="map">` атрибут `data-source="demo"`, а в разметке удалить блок `.dev-note` и бейджи «Демо».

Сейчас на карте 120 **выдуманных** станций. Распределение по городам взято из драфта команды.

### 2. Заявки партнёров → CRM
Файл `js/partner.js`: переопределить `window.EnerGoPartner.submit = async (data) => { … }`. В `data` приходят поля `format`, `name`, `company`, `phone`, `city`, `tp`, `fleet`, `consent`. Строку «Демо: заявка никуда не отправляется» и подпись на экране успеха убрать.

### 3. Тексты и переводы
- Исходный текст написан на русском прямо в разметке. `js/i18n.js` содержит словарь `RU → [UZ, EN]` и шаблоны для динамических строк. Он переводит и то, что скрипты дорисовывают позже: карту, всплывающие подсказки, toast.
- Язык выбирается переключателем в шапке, параметром `?lang=uz|en` или берётся из сохранённого в `localStorage`.
- Для SEO на проде лучше отдавать отдельные URL на каждый язык (`/ru`, `/uz`, `/en`), сгенерированные из этого же словаря.
- Тексты инструкций и условия партнёрства **черновые**: их нужно сверить с эксплуатацией и отделом развития.

### 4. Прочее
- Ссылки на видео (YouTube Shorts), приложения и соцсети заданы прямо в `index.html`. Ссылку на видео 2 «Как закончить зарядку» стоит перепроверить (`e09l-2--gVs`).
- Раздела «Абонементы / EnerGo Club» в демо пока нет, из меню он убран.
