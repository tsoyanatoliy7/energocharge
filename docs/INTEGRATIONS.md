# Интеграции и непроверенные данные

Перед запуском каждый пункт должен быть либо подключён к проверенному источнику, либо убран.

## Помечено на сайте как DEMO
| Где | Что | Файл | Что сделать |
|---|---|---|---|
| Станции | Список станций, статусы, коннекторы, цены, координаты | `src/data/stations.demo.ts` | Подключить API станций (или выгрузку из бэкенда приложения) |
| Станции | Карта — встраиваемый виджет Яндекс Карт с поиском «EnerGo» | `src/lib/site.ts` → `mapWidget` | Своя карта (Яндекс JS API / Mapbox) с данными API |
| EnerGo Club | Пакеты, цены за кВт·ч, сроки, акция Yaqin Taxi | `src/data/club.ts` | Сверить с биллингом/приложением; кнопка «Купить» → deep link в приложение |
| Зарядка в 3 клика | Экраны телефона — схемы, не скриншоты | `src/components/sections/HowTo.tsx` | Заменить на реальные экраны приложения |
| Первый экран | Интерфейс на экране станции при наезде | `src/components/hero/ScreenUI.tsx` | Можно оставить как иллюстрацию или заменить на реальный экран |
| Партнёрство | Форма заявки не отправляет данные | `src/components/sections/Business.tsx` (`onSubmit`) | Обработчик (CRM/Telegram-бот/почта), антиспам, согласие на ПДн |

## Взято из драфта команды, проверить
- Юрлицо «ООО ECORESERVE» и адрес «г. Ташкент, Малая кольцевая автомобильная дорога, 7» (футер).
- Пополнение баланса «банковской картой или через Click».
- Список городов в фильтре станций.
